# 🏢 Flat Manager - ফ্ল্যাট ও মেস ম্যানেজমেন্ট সিস্টেম (PWA)

আধুনিক, রিয়েল-টাইম এবং ফুল-ফিচারযুক্ত ফ্ল্যাট, মেস এবং বাড়ি ভাড়া ম্যানেজমেন্ট প্রগ্রেসিভ ওয়েব অ্যাপ (PWA)। এতে রয়েছে স্বয়ংক্রিয় নোটিফিকেশন সিস্টেম, ভাড়াটিয়া ব্যবস্থাপনা, বিলিং ও ইনভয়েস জেনারেশন, কিচেন ডিউটি রোটেশন, ভিজিটর ট্র্যাকিং এবং আইনি ডকুমেন্ট জেনারেশন।

## 🚀 GitHub এ কোড আপলোড ও আপডেট করার সম্পূর্ণ নির্দেশিকা

### ১. প্রথমবার GitHub এ আপলোড (Initial Push)

আপনার পিসির টার্মিনাল বা কমান্ড প্রম্পট (Terminal / VS Code Terminal / Git Bash) এ গিয়ে নিচের ধাপগুলো সম্পন্ন করুন:

#### ধাপ ১: GitHub এ নতুন রিপোজিটরি তৈরি করুন
1. ব্রাউজারে [GitHub.com](https://github.com) এ লগইন করুন।
2. ওপরের ডানদিকের **`+`** আইকন থেকে **"New repository"** সিলেক্ট করুন।
3. **Repository name** দিন (যেমন: `flat-manager` বা আপনার পছন্দমতো নাম)।
4. Visibility হিসেবে **Public** অথবা **Private** বেছে নিন।
5. *"Initialize this repository with a README"* এ টিক **দিবেন না** (কারণ আমাদের প্রজেক্টে ইতিমধ্যে কোড ও README তৈরি আছে)।
6. **"Create repository"** বাটনে ক্লিক করুন।
7. তৈরি হওয়া রিপোজিটরির URL টি কপি করুন (যেমন: `https://github.com/your-username/flat-manager.git`)।

#### ধাপ ২: লোকাল প্রজেক্টে গিট লিঙ্ক ও পুশ করুন
প্রজেক্টের রুট ফোল্ডারে টার্মিনাল ওপেন করে নিচের কমান্ডগুলো চালান:

```bash
# ১. গিট ইনিশিয়ালাইজ করুন (যদি আগে না করা থাকে)
git init

# ২. মেইন ব্রাঞ্চ নির্বাচন করুন
git branch -M main

# ৩. আপনার GitHub রিপোজিটরি URL যোগ করুন (YOUR_USERNAME ও REPO_NAME পরিবর্তন করুন)
git remote add origin https://github.com/YOUR_USERNAME/REPO_NAME.git

# ৪. সব ফাইল গিট ট্র্যাকিংয়ে যোগ করুন
git add .

# ৫. প্রথম কমিট তৈরি করুন
git commit -m "feat: Initial commit of Flat Manager PWA"

# ৬. GitHub এ কোড পুশ করুন
git push -u origin main
```

### ২. পরবর্তীতে নতুন পরিবর্তন GitHub এ আপডেট করা (Daily Update Flow)

যখনই প্রজেক্টে কোনো নতুন পরিবর্তন, নতুন ফিচার বা বাগ ফিক্স করবেন, তখন মাত্র ৩টি কমান্ড দিয়ে GitHub এ আপডেট করে নিতে পারবেন:

```bash
# ১. পরিবর্তিত সব ফাইল স্টেজে যুক্ত করুন
git add .

# ২. পরিবর্তনের সংক্ষিপ্ত বার্তা দিয়ে কমিট করুন
git commit -m "Update: নতুন ফিচারের বিবরণ এখানে লিখুন"

# ৩. GitHub এ পরিবর্তন পুশ করুন
git push
```

#### প্রয়োজনীয় কিছু সহায়ক গিট কমান্ড:
```bash
# গিট স্ট্যাটাস চেক করতে (কোন কোন ফাইল পরিবর্তিত হয়েছে তা দেখতে)
git status

# কমিট হিস্ট্রি দেখতে
git log --oneline -n 5

# রিমোট রিপোজিটরির বর্তমান লিঙ্ক দেখতে
git remote -v
```

### ৩. GitHub Authentication (Personal Access Token)

২০২১ সাল থেকে GitHub পাসওয়ার্ডের বদলে **Personal Access Token (PAT)** অথবা **SSH Key** ব্যবহার বাধ্যতামূলক করেছে। `git push` করার সময় পাসওয়ার্ড চাইলে আপনার GitHub অ্যাকাউন্টের সাধারণ পাসওয়ার্ডের জায়গায় পার্সোনাল অ্যাক্সেস টোকেন ব্যবহার করতে হবে:

#### পার্সোনাল অ্যাক্সেস টোকেন (PAT) তৈরি করার নিয়ম:
1. GitHub এ যান: **Settings** ➡️ **Developer Settings** ➡️ **Personal access tokens** ➡️ **Tokens (classic)**
2. **Generate new token (classic)** এ ক্লিক করুন।
3. Note এ নাম দিন (যেমন: `FlatManagerDeploy`) এবং Expiration দিন (যেমন: `90 days` বা `No expiration`)।
4. **Select scopes** থেকে **`repo`** বক্সে টিক দিন (Full control of private repositories)।
5. পেজের নিচে **Generate token** এ ক্লিক করুন।
6. প্রাপ্ত টোকেন কোডটি কপি করে সংরক্ষণ করুন (যেমন: `ghp_xxxxxxxxxxxxxxxxxxxx`)।
7. টার্মিনালে `git push` করার সময় **Username** চাইলে আপনার GitHub ইউজারনেম এবং **Password** চাইলে এই টোকেনটি পেস্ট করুন।

## 💻 লোকাল এনভায়রনমেন্টে প্রজেক্ট রান করার নিয়ম

### পূর্বশর্ত:
- [Node.js](https://nodejs.org/) (v18 বা তার পরবর্তী সংস্করণ ইনস্টল থাকতে হবে)
- `npm` বা `bun`

### প্রজেক্ট সেটআপ ও রান:

```bash
# ১. গিট রিপোজিটরি ক্লোন করুন
git clone https://github.com/YOUR_USERNAME/REPO_NAME.git
cd REPO_NAME

# ২. প্যাকেজ বা ডিপেন্ডেন্সি ইনস্টল করুন
npm install

# ৩. লোকাল ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev

# ৪. প্রোডাকশন বিল্ড তৈরি করতে
npm run build
```

ব্রাউজারে `http://localhost:3000` অথবা টার্মিনালে প্রদর্শিত লিঙ্কে প্রবেশ করুন।

## 🌟 অ্যাপের মূল ফিচারসমূহ

1. **রিয়েল-টাইম নোটিফিকেশন সিস্টেম (Auto Notification & In-App Toast)**:
   - কোনো আপডেট (নোটিশ, রুলস, পেমেন্ট অনুমোদন, কিচেন ডিউটি, কমপ্লেইন রিপ্লাই) পোস্ট হওয়ামাত্রই সব সংশ্লিষ্ট ইউজারের কাছে অডিও সংকেত ও ফ্লোটিং নোটিফিকেশন বার পপআপ শো করে।
   - ক্লিক করলেই নির্দিষ্ট বিস্তারিত পাতায় সরাসরি রিডাইরেক্ট হয়।
2. **মালিকের ড্যাশবোর্ড (Owner Dashboard)**:
   - ফ্ল্যাট ও রুম কনফিগারেশন এবং ভাড়া নিয়ন্ত্রণ।
   - ইউটিলিটি বিলিং ও স্বয়ংক্রিয় ইনভয়েস প্রদান।
   - ভাড়াটিয়াদের পেমেন্ট ভেরিফিকেশন ও এপ্রুভাল।
   - অভিযোগ নিষ্পত্তি ও রক্ষণাবেক্ষণ হিসেব।
   - পুলিশ ভেরিফিকেশন ফর্ম যাচাই ও অনুমোদন।
3. **ভাড়াটিয়া ড্যাশবোর্ড (Tenant Dashboard)**:
   - মাসিক ভাড়া ও ইউটিলিটি বিল দেখা ও সরাসরি পরিশোধ রিকোয়েস্ট পাঠানো।
   - ডিজিটাল মানি রিসিপ্ট ভিউ ও ডাউনলোড।
   - রুমমেটদের সাথে কিচেন ডিউটি ট্র্যাকিং ও কমপ্লিট মার্কিং।
   - অভিযোগ বা সার্ভিস রিকোয়েস্ট তৈরি।
   - ছাড়ার নোটিশ (Move-out Notice) সাবমিশন।
4. **পাবলিক পোর্টাল ও এভেইলেবল রুম বুকিং (Public Room Portal)**:
   - খালি থাকা রুমগুলোর তালিকা, ছবি, সুবিধাসমূহ ও বুকিং রিকোয়েস্ট ফর্ম।
5. **ভিজিটর ম্যানেজমেন্ট সিস্টেম (Visitor Tracker)**:
   - মেহমান ও ভিজিটরদের আগমন-প্রস্থান ও ফটো লগ রাখা।
6. **আইনি ডকুমেন্ট ও ভেরিফিকেশন (Legal & Police Verification)**:
   - ভাড়া চুক্তিপত্র (Tenancy Agreement), ভাড়াটিয়া তথ্য ফরম ও পুলিশ ভেরিফিকেশন অটো-জেনারেটর।
7. **PWA ও অফলাইন সুবিধা (Progressive Web App)**:
   - ডিভাইস স্টোরেজ ও ক্লাউড সিঙ্ক সাপোর্ট।
